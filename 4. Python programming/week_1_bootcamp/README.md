# Week 1: Programming bootcamp (3 days, 12h)

- **`day_1_setup_and_first_code/`**: Set up Python, VS Code and Jupyter. Variables, types, built-in functions, strings, f-strings, arithmetic, the `math` library, reading error messages. *No lists yet.*
- **`day_2_lists_conditionals_and_loops/`**: Teach the three code-alongs first (lists, comparison operators, conditional statements), then the lists lab and the conditionals lab, then the loops code-along and lab. The labs depend on each other this way: the lists lab uses `if`, and the conditionals material uses lists.
  - Nested lists are a bonus step in the lists code-along and lab
  - The loops code-along ends with one nested loop example; the nested loops task is the last bonus challenge (5) in the loops lab
- **`day_3_dictionaries/`**: Dictionaries, then lists of dicts
- **`bonus_and_review/`**: Review labs, a hard bonus lab and the optional nested loops code-along, for fast students or homework

**Labs are individual work.** What is not finished in class is finished at home.

Homework (no class time): while loops, tuples and sets.

Files inside each day are numbered in teaching order.
