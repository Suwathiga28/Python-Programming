# Week 2: Functions, robustness and OOP (4 days, 16h)

- **`day_1_functions_and_modules/`**: Functions, arguments, return values, the Food festival lab, modules and project structure
- **`day_2_errors_and_files/`**: try/except, raise, assert, files, CSV and JSON; lab on a messy sales file
- **`day_3_oop_part_1/`**: Classes, `__init__` (the setup method), methods, a `describe()` method, objects holding objects; lab with Product, Order, Customer
- **`day_4_oop_part_2_and_packages/`**: **No notebooks: plain `.py` files run from VS Code.** Encapsulation with methods, light inheritance, importing your own files, a small package; the `sales` package mini project with a check script (S6 distinction criteria)

Files inside each topic are numbered in teaching order.

Code style in this week (kept simple on purpose): plain loops (no comprehensions), no decorators, and no special `__methods__` except `__init__` (plus the empty `__init__.py` file that marks a package).
